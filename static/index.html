    Export everything

    One zip file with all your original audio under readable names, a plain-text note beside each one, a web page that lists and plays everything, a spreadsheet list, a copy of the database and checksums. It opens on any computer without this app. The download starts straight away and your browser shows its progress; keep this tab open until it finishes.

    Download the export (.zip)

    Just the database (titles, tags, notes, marks; no audio): download riffbox.db

    Backup on the server

    The "Back up now" button is not switched on. It needs a folder on the server to write to; the steps are in deploy/PHASE8.md (section 2). The nightly backup script works without it.

    A backup keeps a checked copy of the database (the newest 14) and a copy of every original audio file. It lives on the same server, so it does not protect you if the server is lost. For that, download the export above or pull the backup folder to your own computer.

    Restoring

    There is deliberately no restore button: replacing the live library is the one action that cannot be undone from here. To check that a backup really works, do the practice restore in deploy/PHASE8.md (section 4) on your own computer. If the server is ever lost, the zip above also contains riffbox.db and the audio, which is everything needed.
